# InsightBoard — React Analytics Dashboard

Адаптивная аналитическая панель продаж для портфолио. **Все данные демонстрационные**.

## Возможности
- KPI: выручка, число заказов, средний чек, клиенты
- Фильтры по периоду, каналу и строке поиска
- Графики выручки и каналов (Recharts)
- Список транзакций и экспорт CSV
- Адаптивный интерфейс

## Стек
React 18, Vite 6, Recharts, Lucide Icons, CSS.

## Запуск
```bash
npm install
npm run dev
```
Откройте адрес, указанный Vite (обычно http://localhost:5173). Сборка: `npm run build`.

## Ограничения
Данные генерируются локально, нет авторизации или подключённой аналитической системы. Для реального проекта понадобится API и управление доступом.
